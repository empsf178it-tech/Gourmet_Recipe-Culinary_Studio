# Gourmet Recipe & Culinary Studio

A premium, dark-editorial web application for an artisan bakery and culinary recipe studio.

## 🌟 Overview
**Gourmet Recipe & Culinary Studio** is an editorial culinary platform focused on artisan baking, pastry recipes, signature desserts, culinary education, and professional techniques.

Designed with a **dark luxury visual identity**, the platform combines the feel of a luxury patisserie, culinary magazine, recipe studio, and digital baking journal.

---

## 🚀 Key Features

- **Dark-Only Luxury Design System**: Unified dark theme (`#171311` primary background) with warm ivory typography, copper accents, and gold details across all 10 pages.
- **55 Provided Images Visual Mapping**: Uses all 55 supplied photography assets uniquely across pages, heroes, cards, step-by-step method timelines, and masterclass features.
- **Strict Mobile & Tablet Navbar**: Below `992px`, displays **Brand + Hamburger** only. Launches a full-screen overlay menu with smooth animations and keyboard accessibility.
- **Interactive Recipe Explorer**: Filter recipes by category (Cakes, Pastries, Bread, Chocolate, Tarts, Cookies, Seasonal) and live search recipe titles/ingredients with Vanilla JS.
- **Recipe Detail & Ingredient Checklist**: Step-by-step preparation timeline with method images and persistent interactive ingredient checkboxes stored in `localStorage`.
- **Favorites & Recipe Completion**: Bookmark favorite recipes and track finished baking formulas persisted with `localStorage`.
- **Frontend Authentication & Dashboard**: Demo login, registration, password strength indicator, and user dashboard with animated progress bars and quick stats.
- **Masterclasses & Modal Details**: Interactive studio workshops with dark accessible detail modals.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic document structure & SEO meta tags.
- **CSS3**: Vanilla CSS tokens, custom utility classes, dark luxury styling system, keyframes, and GPU-accelerated transitions.
- **Vanilla JavaScript ES6+**: Modular interactive logic without external frameworks.
- **Bootstrap 5 (via CDN)**: Used for responsive grid, modals, and accordion components without default Bootstrap visual appearance.
